# 6061铝合金研究计划示例 / Synthetic materials example

资料卡是自编简短摘要与来源指引；CSV中12条HV_mean全部为 `synthetic_not_measured`。JSON提供页面填写参考，不是应用的导入/恢复协议。

研究问题：如何研究时效温度与时间对硬度的影响？演示水平为160/180摄氏度和4/8小时，形成四组合。每组合计划三个独立热处理批次，每批一个试样；同试样多个压痕只是技术重复。实施前需另行确认材料前处理、设备、标准和可行范围。当前没有真实试验或材料性能仿真。

在资料页分别导入01参考资料卡和02合成CSV，再按03填写参考建立问题、方向、实验和成果。全因子生成表只给四组合，独立重复与真实实施记录另管。不能从这些合成数值推荐工艺，当前应用也不会自动完成CSV的材料统计。

参考文献：Jia X et al., *Impact of Heat Treatment Parameters on the Plastic Properties of 6061 Aluminum Alloy*, 2025, [DOI:10.3390/ma18081705](https://doi.org/10.3390/ma18081705)。资料卡不含论文全文，摘要不能支持本示例的合成硬度数据。

English: The card is an original short summary, not a paper copy. All twelve hardness rows are synthetic and unmeasured. The JSON is a form-filling reference, not an import/restore format. Four illustrative temperature/time combinations and three independent batches per combination demonstrate planning only. Multiple indents on one specimen are technical replicates. No process recommendation or materials simulation follows from these data.
