# Contributing

[中文](CONTRIBUTING.md) · [README](README.en.md) · [License scope](LICENSES.md)

Read AGENTS.md, the architecture and development notes first. Describe a reproducible trigger, the resulting behavior, affected layers and the checks actually run.

Research and learning remain parallel modules. Put method judgement in aesthetic, authorization/execution in functional, and provenance/versioning in assets. Web and MCP share the Runtime facade. Breaking contract changes need a new version and compatibility adapters.

Use original or redistributable synthetic fixtures. Preserve upstream versions, licenses and modification notices. Never contribute personal records, credentials, private project archives, textbooks or material you cannot redistribute. Report quote integrity, numerical checks, domain review and real-world effects separately.

Run relevant existing tests, scripts/check_public_source.py and a credential scanner before publishing. Runtime workflow changes require the real HTTP/MCP verification. New model adapters must specify units, provenance, seeds, resource limits, failure behavior and calibration boundaries.

Original contributions use the project MIT license. Third-party material retains its own license.
