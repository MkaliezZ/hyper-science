# 超维科研使用说明

[English](USER-GUIDE.en.md) · [首页](../README.md)

1. 执行首页的安装与启动命令。首次在主入口选择本人身份并填写名称；点击“超维科研”。默认脚本建立仓库内独立实例。
2. 填项目名称、研究方向及说明，点击“建立项目”。在“问题与记录”写研究问题、情境、目标、限制并保存问题卡。
3. 到“资料与检索”，粘贴文字或展开“导入本地原件”并选择UTF-8文字/含文字PDF。每份不超过8MB，PDF最多50页；首版不做扫描OCR和Office转换。保留出处、内容范围和来源声明。
4. 在项目内检索后核对所引版本；若要查外部文献，主动填写检索词并选择Crossref/OpenAlex/arXiv。公开检索只发送查询参数；取得的元数据不能自动当论文正文。
5. 在“方向与计划”先写本人想法、候选路线、比较标准和替代解释，再生成探索底稿。可选AI候选需要先配置自有模型，并明确选择发送的材料。保存采用的方法、步骤、分析和局限。
6. 需要实验时，到“实验与模拟”保存研究单位、比较条件、测量、独立重复、随机化、控制与推翻条件。选择实验，再选两水平全因子等方法并生成计划表。表内组合数不等于真实独立重复数，实施记录需另行保留。
7. 内置模拟为固定排队模型。填写单位、参数来源、假设、重复与种子，再运行。它不会预测材料硬度或组织；需要材料模型时另接执行器。任务失败后查看原因，可取消或明确重试，避免重复外部查询。
8. 在“成果与复盘”区分发现、解释、假设和方案。选依据并填写一致的原文摘录，写清局限和下一步，保存简报；可检查表达、反馈、修订和导出。引用完整性核对不代替人工判断语义支持。

## 材料学案例

按 [6061示例](../examples/materials-6061/README.md)导入资料卡和合成CSV。研究单位是独立热处理批次；每试样多个压痕属于技术重复。温度160/180与时长4/8只是演示水平；四组合、每组合三个独立批次是计划，不是已经完成的12次真实试验。应用当前不会自动对CSV做材料统计。

## 数据、联动和恢复

默认启动使用data/science；关闭后保留数据，重启继续读取。不要把该目录或项目JSON公开。项目JSON用于审查归档，不能替代完整恢复包；身份、配对和所有模块通过主入口的加密备份恢复。

若科研与伴学使用同一本机实例，明确选择本人伴学文字资料后才能联动；来源修订后旧引用可能失效，需要重新核对。新实例不会自动取得其他实例的身份或资料。保留原数据目录，接入现有实例前先使用原入口备份，不修改数据库口令。

## 常见问题

- “科研执行环境尚未安装”：执行scripts/setup_research.ps1，再用-VerifyOnly核对。
- PDF没提取到文字：检查是否扫描件；先在有权处理的本地工具中取得文字，再导入。
- 资料或简报版本冲突：刷新并读取最新版本，再保存；不要覆盖他人的变更。
- 找不到AI结果：确认模型已配置、所需材料已明确选择、任务状态成功。未配置模型仍可完成手工流程。
